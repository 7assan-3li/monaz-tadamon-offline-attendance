# مهارة الصياغة اللغوية والمصطلحات المعتمدة (Human Sports Copywriting)
**تطبيق نادي تضامن حضرموت | دليل النبرة والمصطلحات الإدارية الرياضية الأصيلة**

الهدف الصارم لهذه المهارة هو **محو أي أثر للترجمة الآلية أو أسلوب الذكاء الاصطناعي الركيك**، وجعل كل كلمة، زر، تنبيه، وترويسة في التطبيق تبدو وكأنها كُتبت بيد **إداري رياضي حضرمي متمرس**، باستخدام المصطلحات الرياضية واللائحية المعتمدة رسمياً في النادي.

---

## 1. فلسفة النبرة الصوتية (Tone of Voice)
* **إدارية رياضية واثقة ومباشرة:** الكلمات موجزة، واضحة، ومهنية، تناسب سرعة وضغط الميدان.
* **البشرية والأصالة:** التحدث بلغة عربية فصحى معاصرة وسليمة، دون تكلف لغوي ودون ركاكة آلية.
* **الفعل المباشر:** استخدام صيغة المصدر أو الأمر المباشر للأزرار والإجراءات، وحظر صيغ الحشو مثل: *(قم بالضغط على...)* أو *(يرجى النقر لتنفيذ...)*.

| السياق | ❌ النص الآلي المرفوض (AI / Robotic Style) | ✅ النص البشري المعتمد (Authentic Club Copy) |
| :--- | :--- | :--- |
| **زر بدء اليوم** | قم بإنشاء جلسة تمرين جديدة لليوم | **بدء تحضير تمرين اليوم** |
| **التحضير السريع** | اجعل جميع المستخدمين في حالة حضور | **تحديد الجميع حاضر** |
| **اعتماد الحضور** | تم تنفيذ عملية الحفظ بنجاح تام | **تم اعتماد الكشف بنجاح** |
| **النواقص قبل الاعتماد** | خطأ تحقق: الحقول تحتوي على قيم فارغة | **يوجد لاعبون لم تُرصد حالتهم بعد** |
| **زر الإلغاء** | إلغاء الأمر والخروج | **تراجع** أو **إلغاء** |

| **استحقاق اللاعب** | مجموع نقاط الاستحقاق المالي التراكمي | **الاستحقاق الرياضي** *(أيام/حصص)* |

| **تأكيد الحذف/الأرشفة** | هل أنت متأكد من رغبتك في حذف هذا الكائن؟ | **أرشفة اللاعب؟ لن يُحذف سجله التاريخي السابقة** |

## 3. قاموس المصطلحات الرسمية المعتمدة (Club Terminology Lexicon)

### أ. الكشوفات والتقارير:
* **«حافظة التحضير مفتوحة»:** الاسم المعتمد للكشف الشهري المصفوفي (الذي يعرض أسماء اللاعبين وتواريخ التمارين).
* **«كشف التحضير مع خلاصة الإداري»:** الاسم المعتمد للتقرير التجميعي النهائي.
* **«خلاصة الإداري»:** الجدول التحليلي الذي يجمع إجمالي حضور وغياب واستحقاق وملاحظات كل لاعب.
* **«الاستحقاق الرياضي»:** المصطلح المعتمد لعدد الأيام/الحصص المؤهلة للمشاركة الرياضية فقط (ممنوع منعاً باتاً استخدام كلمة "مالي" أو "مكافأة" في V1).

### ب. حالات الحضور والغياب (موحدة الألوان والمسميات):
* **حاضر** (أخضر).
* **غائب بعذر** (أصفر/برتقالي).
* **غائب بدون عذر** (أحمر).
* **متأخر** (مع خانة الدقائق إن فُعّلت).
* **معذور/مصاب** (في حال وجود فترة إجازة أو إصابة مثبتة).

### ج. هيكل النادي والفرق:
* **«الفريق الأول»** / **«فئة الشباب»** / **«فئة الناشئين»** / **«فئة البراعم»**.
* **«الحصة التدريبية»** أو **«التمرين»** (مسائي / صباحي).
* **«مباراة ودية»** / **«مباراة رسمية»** / **«اجتماع فني»**.
* **«رئيس النشاط الرياضي»** / **«إداري الفريق»** / **«مدير النادي»**.

### د. الترخيص والأمان:
* **«معرّف الجهاز»** (وليس "كود العتاد" أو "Machine Identifier").
* **«كود التفعيل»** (وليس "رمز المفتاح التسلسلي").
* **«صلاحية الباقة»** و **«الأيام المتبقية»**.
* **«رمز الحماية (PIN)»**.
* **«نسخة احتياطية لقاعدة البيانات»**.

## 4. القواعد اللغوية والصياغة الميكروية (Microcopy Guidelines)

1. **حظر ترجمة الضمائر الحرفية الإنجليزية:**
   * ❌ لا تقل: *"ملفك الشخصي"*، *"فريقك"*، *"الخاص بك"*.
   * ✅ قل: **«ملف اللاعب»**، **«بيانات الفريق»**، **«بيانات النادي»**.
2. **صحة الهمزات العربية وعلامات الترقيم:**
   * التزام تام بهمزة القطع وهمزة الوصل: *(إداري، إجمالي، استحقاق، اعتماد، انتقال، أرشيف)*.
   * استخدام الفاصلة العربية (،) وليس الإنجليزية (,).
   * النقطتان الرأسيتان (:) بعد التسميات التوضيحية (مثل: `الفريق: الفريق الأول`).
3. **صياغة رسائل التنبيه والخطأ (Constructive Microcopy):**
   * اذكر المشكلة مباشرة ثم وجه للحل بوضوح:
     * ❌ *"حدث خطأ غير متوقع في النظام!"*
     * ✅ **«تعذر استعادة النسخة؛ الملف المحدد تالف أو غير متوافق»**.
4. **شريط حالة الباقة العلوي:**
   * صياغة رصينة وموجزة:
     * **«نادي تضامن حضرموت | باقة الموسم الرياضي | المتبقي: 140 يوماً»**.

---

## 5. قائمة التحقق اللغوية قبل اعتماد أي واجهة (Copywriting Checklist):
- [ ] هل تخلو النصوص تماماً من المصطلحات المترجمة ركيكاً مثل "الخاص بك" أو "تم بنجاح كذا"؟
- [ ] هل تم استخدام المصطلحات الرسمية للنادي («حافظة التحضير مفتوحة»، «خلاصة الإداري»، «الاستحقاق الرياضي»)؟
- [ ] هل أسماء الأزرار بصيغة مباشرة وموجزة (مثل: «بدء تحضير تمرين اليوم»، «تحديد الجميع حاضر»)؟
- [ ] هل الهمزات وعلامات الترقيم العربية صحيحة 100%؟
- [ ] هل رسائل الخطأ تشرح المشكلة والحل بلغة يفهمها إداري النادي دون مصطلحات برمجية معقدة؟
